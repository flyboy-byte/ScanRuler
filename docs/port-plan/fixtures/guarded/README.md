# Registered guarded-command inputs

1,972 deterministic control profiles. No original result, private scan or Rust
output is an input. Each side constructs a fresh actual registered command and
its own document/history/activity/timer state. `build-guarded.mjs` builds the full
pinned graph; it only exposes private functions/counters in a temporary archive.
The original TypeScript checkout remains untouched.

The first 1,120 cases are the full product of guarded/interrupt, history off/on,
four busy answers, seven immediate/pending/timeout outcomes, five label policies
and deferred off/on. Next 72 cases drive start/progress/clear listeners, caller
progress and before/after capture faults. All earlier profiles remain in place.
Append-only extensions cover thrown strings, stale imports, failed/falsy String
conversion, nested interrupt history sharing, conversion/capture reentry, history
clear/epoch invalidation, synchronous label-error ordering, strict discards and
plugin stopping/done, resolved-candidate-then-throw precedence, scene routing and
abort-listener function identity. The source and native host clocks independently
sample the same fixed input millisecond 1234; the native workspace default is the
pinned shell's `elements`.

Every frame compares result/full UTF-16 error and reason identity, document value,
capture counts, running/current/deferred/progress, full changed history patches,
labels/workspace/group, history flags/revision/paused, timers, ordered effects,
Unhandled count, stale timestamp, nested reply and plugin done observation.
The Rust side receives only the control fields. Actual family state remains the
next measurement slice, not the numeric fixture participant used to audit history.

`SCANRULER_GUARDED_SABOTAGE=1` deliberately changes an actual resulting state
value and must make the real comparison fail. Red runs retain original input and
original bytes before evaluating Rust, including when native evaluation panics.
All previous deadline/execute/scene/numerical/parser/Chrome cases remain mandatory.
