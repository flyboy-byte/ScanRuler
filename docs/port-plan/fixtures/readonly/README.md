# Registered read-only and job inputs

2,591 deterministic, original-first control profiles. Each side independently
constructs a fresh actual registered command/session. Inputs contain no original
outputs. The prior 1,968 inputs remain verbatim; appended cases retain stable IDs.

The product varies read-only/interrupt precedence, scene routing, deferred,
null/ready/pending/thrown settlement, body success/rejection/synchronous typed
throw/pending/timeout/undefined, absent/empty/job names and busy guards. Extensions
cover mutation/interrupt/unknown/invalid admission jobs, full byte/large/stale
results, shared scene contention, 101 simultaneous runs and 100-record eviction,
lone UTF-16 job names, synchronous clock/Date failure and detached reaction faults,
asynchronous failed settlers, and separate Date.now/new Date fault sites. Native settlement uses the actual callback
registry. All old guarded/deadline/execute/numerical/parser/browser corpora remain.

Five full frames compare binary owned values (including UTF-16 and bytes), exact
caller errors and typed/signal identity, actual document effects, activity/current,
history metadata/capture count, timer/ordered effect log, all and filtered recent
records/results/omissions, stale state and detached failures. No source result is
fed to Rust. Real scan/measurement models are a separate required continuation.

`SCANRULER_READONLY_SABOTAGE=1` changes actual native document effects from 1 to 9
and must fail the complete source comparison. Changed/missing-output checks are
retained for every case. Original bytes are saved before native observation.
