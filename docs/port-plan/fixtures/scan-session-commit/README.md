# Actual prepared scan/session controls

800 independent original-first profiles; no original result or private scan
is an input. Full original scanImport.commitScan, real stores, surfaces, scan events
and history operate on independent prepared mesh/source payloads. The same stable
controls construct native assets and state; prepared consumer evidence does not
claim the unported worker/parser/render preparation or scan.open continuation.

Profiles cover prepared/null, file/session reference, held state and persistent
IDs/preferences, auto/manual thickness, viewport/no-viewport, absent/empty/full
colour arrays, successive replacement, faulting providers/store listeners, and
seeded f32 buffers. Source provider callbacks are explicit input controls; the
original consumer body and state mutators are never replaced by stubs.

Preregistered numeric policy: all keys/shapes/text/bytes/IDs/counts/status/effects
compare exactly. Only bounds-derived modelSize, brush diameter and thickness
suggestions inherit geometry.bounds' existing 1e-12*(1+abs(reference)) tolerance;
this does not change any earlier gate. Values are retained in full, without
rounding or dropping floats. No candidate is accepted by this fixture plan.

Original full-store graphs run in fresh processes of 64 cases to bound module-cache
memory. All 800 cases retain their independent sessions, inputs, seeds and full
observables; batching is not a reduced corpus or altered comparison gate.

Append-only profiles exercise live store unsubscribe/add with reentrant publication,
and scan-loaded snapshot iteration with duplicated identities removed/added during
emission. The original 672 inputs and every prior observable remain in place.
