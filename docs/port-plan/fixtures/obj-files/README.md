# Authored file/companion inputs

87 fixed cases: 41 filename/classification observations, 14 hand-authored state
traces, and eight traces for each seed 1/7/99/1039. Generated by
`tools/generate_obj_files_cases.py`; AGPL-3.0-only, no downloaded/private assets.
Source-only capture: `evidence/2026-11-02-obj-files-source.json`, before Rust code.

Input: mode byte. Mode0 has one length-prefixed UTF-8 name. Mode1 has u32 file
count, name/blob records, u32 operation count; each operation has byte tag and
u32-counted file IDs. Tags1 bundle,2 query companions,3 preserve bytes.
All counts/lengths/IDs are little-endian u32; IDs reference independent file
objects in input order. Output FLS1 + mode. Mode0 contains extension, six boolean
classifier bytes, six picker/display constants. Mode1 contains operation count,
each tag and full result, then every file's complete association list after that
operation. Bundle null is u32 MAX; bytes results are ordered name/blob records.
No original output or expected answer is ever an input to Rust.
